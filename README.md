  # 🏀 Баскетбол 3D — Броски по периметру

Браузерная 3D-игра: серия из 10 бросков с разных точек площадки (2 и 3 очка) против соперника-ИИ. Русскоязычная озвучка диктора, три уровня сложности, овертайм «внезапная смерть». Установка не нужна — игра работает прямо в браузере.

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| `← →` | Прицел |
| `↑ ↓` | Дуга броска |
| `ПРОБЕЛ` | Держать = сила, отпустить в зелёной зоне = бросок |
| `P` | Пауза |
| `M` | Звук вкл/выкл |
| `V` | Озвучка вкл/выкл |

На телефонах и планшетах автоматически появляются экранные кнопки.

## ⚙️ Особенности

- 🏟️ Полноценная 3D-арена: паркет, трибуны, зрители, прожекторы (WebGL / Three.js)
- 🎯 10 точек броска: штрафная, крылья, углы, тройная дуга
- 🤖 Соперник-ИИ с тремя уровнями сложности
- 🗣️ Русский диктор и анимация лица игрока (Web Speech API)
- 🔊 Все звуки синтезируются на лету (Web Audio API) — ни одного аудиофайла
- 📱 Адаптация под мобильные устройства и слабые девайсы
- 🔌 Работает офлайн, без рекламы и трекеров

## 🚀 Запуск

**Онлайн (GitHub Pages):**
1. Залейте `index.html` в репозиторий.
2. Settings → Pages → Branch: `main` → Save.
3. Игра доступна по адресу `https://ВАШ_ЛОГИН.github.io/basketball-3d-perimeter/`

**Локально:** откройте `index.html` через любой веб-сервер (например, `npx serve` или Live Server в VS Code).

HTML5 · CSS3 · JavaScript (ES Modules) · Three.js r163 · Web Audio API · Web Speech API
